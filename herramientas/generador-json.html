Generador de JSON

Arma el archivo (o fragmento) de contenido a partir de un formulario, en vez de escribir el JSON a mano.

Herramienta interna, no pública. No está enlazada desde el menú del sitio y no escribe nada en el repositorio.
  1. Completa el formulario del tipo de contenido que quieras crear.
  2. Descarga o copia el JSON generado.
  3. Colócalo tú mismo en la carpeta correspondiente (y actualiza el index.json si aplica — la herramienta te lo recuerda en cada caso).
  4. Haz commit y push como siempre.
