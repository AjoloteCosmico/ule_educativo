# Política de Anuncios — ule educativo\n\n## Regla principal de cantidad\n\nCada página que tenga sección de anuncios debe reservar **3 espacios de anuncio**.\n\n- Si la fuente de datos encuentra **3 o más anuncios vigentes y aplicables a la página**, se seleccionan exactamente **3 anuncios distintos**.\n- Si encuentra **1 o 2 anuncios**, se muestran todos los disponibles.\n- Si no encuentra ninguno, la sección completa se oculta.\n- Nunca se inventan anuncios, se duplican anuncios para rellenar espacios ni se muestran más de 3 simultáneamente.\n- La selección se hace una sola vez por página y los tres slots reciben anuncios distintos del mismo conjunto seleccionado.\n- La selección usa `peso` como ponderación, pero sin reemplazo.\n- La regla aplica tanto a `data/anuncios.json` como a los anuncios entregados por la API/DB.\n\n## Filtrado\n\nAntes de seleccionar se comprueba:\n\n1. `activo === true`.\n2. La fecha actual está dentro de `vigencia_inicio` y `vigencia_fin`, cuando existen.\n3. El anuncio permite la página actual o contiene `"todas"`.\n4. Del conjunto resultante se seleccionan como máximo 3.\n\nLas páginas mantienen la sección de anuncios al final del contenido principal para no competir con los componentes editoriales importantes.\n\n## Integración\n\nLos espacios se marcan con `data-ad-slot` dentro de un contenedor `data-ad-slots`. `js/ads.js` es responsable de seleccionar y renderizar los anuncios; las páginas no seleccionan anuncios por su cuenta.\n\nEn escritorio los tres anuncios forman una fila de tres columnas. En pantallas pequeñas se apilan verticalmente.\n\n## Selección ponderada\n\n`peso` determina la probabilidad relativa de selección. La selección es **sin reemplazo**, por lo que el mismo anuncio nunca ocupa dos slots de la misma página.\n\nNo se guarda historial de impresiones ni clics en fase 1.\n\n## Fuente de datos\n\nLos anuncios se cargan exclusivamente mediante `ULE.loader.loadAds()`. El loader puede usar JSON local o la API; el componente de anuncios no depende directamente de una implementación concreta de almacenamiento.\n\n## Contenido y accesibilidad\n\nSe mantienen las reglas existentes para `imagen_alt`, `slogan`, `contacto`, `descripcion`, vigencia, enlaces y relación temática con el proyecto. La ausencia de imagen no impide publicar el anuncio: `<ad-card>` utiliza su fallback visual.\n\n## Mantenimiento\n\nCuando cambie el contrato de anuncios, primero se actualiza esta política y después `js/ads.js`, conservando la regla de **hasta 3 anuncios disponibles por página y 3 como máximo**.\n
